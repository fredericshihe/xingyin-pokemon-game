# 宝可梦全面重新分配计划

## 一、设计原则

### 1. 核心目标
- **渐进式解锁**：玩家通过战斗逐步解锁更多宝可梦
- **主题一致性**：每个地图的宝可梦符合生态主题
- **挑战性递增**：训练师和试炼难度逐步提升
- **无重复体验**：避免不同地图、不同训练师使用相同阵容
- **完整覆盖**：利用所有151只宝可梦，包括当前未使用的14只

### 2. 分配层级
```
地图生态系统
├── 野生宝可梦池（6-8种）- 玩家最容易遇到
├── 普通训练师（4人，每人2只）- 展示地图特色
├── 部下训练师（3人，每人3只）- 混合野生+试炼
├── Boss训练师（1人，6只）- 最强阵容+专属稀有
└── 区域试炼（4阶段解锁）
    ├── 第1批（2-3种）- 击败1次解锁
    ├── 第2批（2-3种）- 击败2次解锁
    ├── 第3批（2-3种）- 击败3次解锁
    └── 第4批（2-3种）- 击败4次解锁
```

### 3. 稀有度分级
- **常见**（野生池）：weight 24-30，基础形态
- **少见**（试炼1-2批）：weight 12-18，进化形态
- **稀有**（试炼3-4批）：weight 6-10，最终进化/特殊宝可梦
- **极稀有**（Boss专属）：weight 18，地图标志性宝可梦
- **传说**（仅最终地图）：weight 5-10，超梦/梦幻/三神鸟

## 二、当前问题总结

### 严重问题
1. **铁木营地**：试炼池等级24-47级，跨度23级
2. **贝壳海岸**：包含喷火龙（火系），与海岸主题不符
3. **14只宝可梦未使用**：11铁甲蛹、27穿山鼠、59风速狗、64勇基拉、75隆隆石、84嘟嘟、89臭臭泥、118角金鱼、123飞天螳螂、136火伊布、148哈克龙、149快龙、150超梦、151梦幻

### 中等问题
4. 部分地图主题不一致
5. 训练师阵容重复度高
6. 试炼池大小不均（8-18种）

## 五、实施步骤

### 阶段1：数据准备
1. 整理所有151只宝可梦的完整数据（类型、进化链、等级范围）
2. 确认每个地图的主题和等级范围
3. 验证进化链的完整性

### 阶段2：野生池重构
1. 按地图主题重新分配野生宝可梦池
2. 确保每个地图6-8种
3. 移除主题不符的宝可梦

### 阶段3：试炼池重构
1. 按4阶段分批设计试炼池
2. 每个地图10-12种
3. 严格控制等级范围在地图范围内
4. 传说宝可梦仅限最终地图

### 阶段4：训练师阵容重构
1. 重新设计所有训练师阵容
2. 确保无重复
3. 匹配地图主题

### 阶段5：Boss专属调整
1. 为每个Boss选择标志性宝可梦
2. 确保Boss阵容最强且多样

### 阶段6：测试验证
1. 验证所有151只宝可梦都被使用
2. 检查等级范围合理性
3. 测试难度曲线
4. 确认无重复配置
