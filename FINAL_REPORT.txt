🎯 核心功能展示
───────────────────────────────────────────────────────────────

1. 自动下载
   npm run download:audio

2. 自动压缩
   npm run compress:audio

3. 播放技能音效
   await gameAudio.playMoveSfx('ember')

4. 预加载音效
   await gameAudio.preloadMoveSfx(['ember', 'watergun'])

5. 自定义参数
   await gameAudio.playMoveSfx('ember', { volume: 0.8 })
