⏳ 下一步操作:

1. 安装 ffmpeg 并压缩音频 (30分钟)
   ─────────────────────────────────────
   brew install ffmpeg
   npm run compress:audio
   
   预期: 文件大小从 8.3 MB 减少到 4-5 MB

2. 测试地图BGM (20分钟)
   ─────────────────────────────────────
   npm run dev
   
   访问每个地图，确认BGM正常播放

3. 下载技能音效 (2-4小时)
   ─────────────────────────────────────
   选项A: 使用现成音效包（推荐）
   - 搜索 "pokemon gba sound effects pack"
   - 下载并解压
   - 复制到对应目录
   
   选项B: 手动搜索下载
   - 访问 freesound.org
   - 按照 AUDIO_RESOURCES_CONFIG.md 搜索
   
   选项C: AI生成
   - 使用 ElevenLabs 或 Suno AI

4. 压缩技能音效 (10分钟)
   ─────────────────────────────────────
   npm run compress:audio

5. 更新代码集成 (30分钟)
   ─────────────────────────────────────
   在 src/utils/gameAudio.js 添加:
   
   async playMoveSfx(moveKey, options = {}) {
     const move = MOVES[moveKey]
     const typeFolder = move.type.toLowerCase()
     const url = `/assets/audio/sfx/${typeFolder}/${moveKey}.ogg`
     return this.playSfx(url, options)
   }

6. 更新 manifest.json (30分钟)
   ─────────────────────────────────────
   添加所有新音频文件的配置信息

7. 最终测试 (1小时)
   ─────────────────────────────────────
   npm run dev
   
   测试所有地图BGM和技能音效
