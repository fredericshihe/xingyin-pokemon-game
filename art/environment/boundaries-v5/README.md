# 地图专属边界地貌 · V5

本轮在保留原场景的基础上，替换跨地图重复出现的通用白石围边，并把主题布景移入可用的地图内部。贝壳海岸沿用已有海岸地貌。道路、遇敌草丛、水体、泉水、试炼场、NPC、隐藏入口与事件坐标不变。

13 套 Blender 原创地貌，每套 12 种独立几何，共 156 个 GLB。实际选用 144 个；同种新模型每图至多一次，仅属于它的目标地图。原始数据中的 74 件通用白石保留记录但停止渲染，地图渲染器也停止自动补通用白石。其他旧场景继续保留，其中 67 件天然树木、岩体使用安全的显示放大比例。14 图共摆放 190 件主题场景道具，每图过半处于内部。

## 源文件与构建

本目录的 13 个 `.blend` 为可编辑的分地图素材集合。作者脚本 `scripts/blender/build_biome_boundaries.py` 调用同仓库 `environment_modeling.py`；不使用外部下载模型。生成物采用单网格、单材质、顶点色、无纹理、无骨骼或动画，合计 410,308 字节、30,042 三角面。Draco 压缩后再解码测量，落地基点误差小于 0.005。

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/blender/build_biome_boundaries.py
node scripts/prepare-boundary-environment-assets.mjs
node scripts/measure-original-environment.mjs
node scripts/generate-map-environment-layouts.mjs
npm run generate:map-manifest
```

布局在构建前离线求解；运行时仅载入固定数据，沿用静态实例化和分块裁剪。模型的旋转包围盒避开道路、草丛、事件交互空间、水域、可见原模型及其他新增模型；高模型额外避让互动点视线。自然地貌使用不规则大小和小角度错落，设施正面沿道路朝向。

新增实体只在空地添加独立碰撞掩码，不改地形格。所有原有可通行分区保持连通；旧存档若落在新增实体里，会局部寻找安全落点，不触发步数或遇敌。

## 验证

- `npm run map:audit-boundaries`：156 种归一化几何互异，glTF 零错误、零警告；地图归属、落地基点、预算、144 处摆放净空全部通过。
- `npm run map:audit-composition` 和 `npm run map:audit-exclusive-assets`：原始数据与保护对象保留，224 个原主题素材继续通过几何验证。
- `npm run map:audit-environment-navigation`：163 个实体碰撞格与可见模型对应，全部原有可通行分区连通，事件入口通畅，旧存档落点恢复通过。
- 浏览器在 10 张具有新增地面碰撞的地图验证实际按键阻挡、邻格移动、旧存档落点恢复；雾湖靠近试炼场的配景调整后单独复测。
- 14 图最终总览无 HTTP 或脚本错误；地图流程、隐藏区域规则、天王道路净空、机关可见性、铁壁/龙穹规则及入口预加载检查通过。地图流程审计仍有原有队伍数量、进化阶段和未装饰地块建议，不是新布局阻塞错误。
