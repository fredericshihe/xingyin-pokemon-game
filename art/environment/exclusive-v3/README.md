建模源文件位于当前目录，按地图分别保存 .blend。生成脚本为 scripts/blender/build_map_exclusive_sets.py 和 exclusive_landscapes.py，只有基础几何建模函数共用；没有导入公共素材，也没有把旧模型换色或改名后分配给各图。

每件模型为单网格、单材质、顶点色和 Draco 压缩，无纹理或动画。224 件共 634988 字节、52836 三角面。独立审计会比较去除平移/整体缩放影响的模型顶点几何，防止改色、改名或缩放副本混入。

地图仍使用已有静态分块实例化。本轮实际使用 175 件新模型，每图 7–16 件，每种只放一处。每图编排 4 组有用途关联的小景；熔炉、备料、检修分区，渔棚、湿岸、水湾分区，模型不再跨组补位。没有安全空位的模型保留在资源库中，不强行塞入场景。建筑、家具、配件、花木按真实尺寸分级，设施正面朝向邻近道路。陆地装饰仅放在不可通行背景或外缘，水生模型须完整落在现有水域内；所有新增模型避开全部原有装饰的包围盒；道路、遇敌草丛、水域、桥梁、机关、NPC 等原样保留。跨地图独占约束只针对新增套装，原有景物继续保留。

重建：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/blender/build_map_exclusive_sets.py
npm run environment:prepare
npm run generate:map-manifest
node scripts/audit-map-exclusive-assets.mjs
node scripts/audit-map-environment-composition.mjs
```

最终画面与本轮性能结果见 VALIDATION.md；先前整体替换布景的验收结论不再适用于本轮。
