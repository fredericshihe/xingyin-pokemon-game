把当前 `44x36` 的新手山谷扩展为一个完整的 `100x100` 主章节地图，并升级为一个有地形逻辑、道路逻辑、资源密度、区域生态、固定训练师、隐藏 Boss、道具探索、野生宝可梦进度档位的章节地图。

## 4. 技术路线：短期落地与长期兼容

### 4.1 短期路线

短期继续基于当前可运行体系：

```text
my_first_map.js
  -> mapGrid / visualPaths / waterBodies / bridges / decorativeObjects / encounterZones
ThreeLowPolyMap.jsx
  -> 渲染、移动、区域提示、遇敌触发
encounterTables.js
  -> 区域物种池
mapEvents.js / mapGameplay.js
  -> 训练师、Boss、道具、隐藏点、进度
```

优点：

- 与当前项目最贴近。
- 不需要先迁移到 Tiled/Phaser 才能完成 100x100。
- 可以逐步验证地图数据、存档兼容和野生生态。

### 4.2 长期路线

长期保留 `MAP_SYSTEM_REBUILD_PLAN.md` 的 Phaser/Tiled 架构方向：

```text
React：登录、背包、队伍、图鉴、战斗、弹窗
Phaser：地图渲染、镜头、移动、碰撞、地图事件
Tiled：Ground / Decoration / Collision / Grass / Events / Above
Supabase：账号、云存档、老师奖励、地图进度
```

因此本次新增的事件配置和玩法配置，应尽量接近 Tiled Object Layer 的表达方式：每个 NPC、道具、隐藏点、Boss、传送点都有稳定 `id/type/x/y/properties`，未来迁移不会重写设计。

### 4.3 坐标与数据约定

后续所有地图相关数据统一使用逻辑网格坐标：

- 坐标原点为左上角，`x` 向右递增，`y` 向下递增。

- 旧地图 `44x36` 保留区域为 `0 <= x <= 43`、`0 <= y <= 35`。

## 5. 地形与道路总设计

### 5.1 地形因果

水系：

- 北部山脊 `W` 是最高点。
- 瀑布源流入旧图东湖。
- 水继续向东南形成月镜湿地。
- 最后进入河口钓营和东岸海湾。

山体与边缘：

- 北边用山脊、碎石坡、瀑布源封边。
- 东边用海湾、码头、棕榈、水面封边。
- 南边用蘑菇幽林、河口、岩壁封边。
- 东南角用岩场和废弃金属场封边。

道路：

- 主路从 `S` 出生营地出发，经旧东口、`B1` 湿地桥、`O` 前哨、农田、`B3` 河口桥、`B2` 岩场桥，形成章节推进线。
- 次路不再只保留一条练级环，而是拆成北山脊环、湿地栈道环、东岸船骸环、采木高地环、幽林遗迹环、农田水渠环、河口沙洲环和岩场废场回环。
- 小径必须服务探索：每条小径尽头至少对应隐藏点、可见道具、稀有草丛、观景地标、训练师绕后路线或未来入口之一。
- 盲端奖励支路允许存在，但不允许空走。超过 `8-12` 格的盲端必须给明确视觉诱因，例如灯笼、碎木栈道、石阶、船骸、墓碑、废铁、蘑菇光点或路牌。

桥位：

- `B1`：旧东口到湿地第一座桥，承担新区域入口。
- `B2`：岩场训练区桥，承担后段挑战入口。
- `B3`：农田与河口桥，承担南部环线收束。

分支密度验收：

- 从任意主路节点走 `12-18` 格，至少能看到一个支路入口、地标或隐藏提示。
- 每个大区至少有 `1` 条环线或半环线，不能只有一条穿区道路。
- 全图至少 `14` 个隐藏微区域，其中第一版落地不少于 `8` 个。
- 盲端支路长度控制在 `5-14` 格，超过 `14` 格必须变成环线或放置中途景观点。
- 隐藏入口不依赖像素级穿墙；玩家应能通过素材异常、路面变化、灯光、道具或地形缺口推断。
- 支路不得把野生遇敌区直接盖在桥面、前哨中心、恢复点中心或 Boss 开战点上。

### 5.5 连通性与卡点规则

扩图落地后，必须把地图当作“路线图”验收，而不是只检查画面是否好看。

关键可达性：

| 起点 | 终点 | 必须可达 | 说明 |
|---|---|---|---|
| `S` 出生营地 | 旧东口 | 是 | 保留旧地图主出口 |
| `S` 出生营地 | 旧南口 | 是 | 保留旧地图练级出口 |
| 旧东口 | `B1` | 是 | 新区域第一推进口 |
| `B1` | `O` 前哨 | 是 | 到达章节目标提示点 |
| `O` 前哨 | `G1/G2/G3` | 是 | 三名部下都不能被进度锁死 |
| `O` 前哨 | `B` Boss | 条件可达 | 物理可达，互动需 3/3 部下解锁 |
| `O` 前哨 | `H` 恢复点 | 是 | Boss 前补给环线 |
| `O` 前哨 | `C` 连战点 | 是 | 可选挑战，不挡主线 |
| Boss 区 | 地图出口/回城路线 | 是 | 击败或失败后都能离开 |

道路规则：

- 主路最窄处至少保留 `3` 格可通行宽度，桥面可短暂收窄到 `2` 格。
- 桥头前后 `2-3` 格不要放大型装饰、训练师、隐藏点和随机遇敌触发区。
- 训练师站位不能堵住唯一道路；若需要拦路，应留出对话后退空间。
- 隐藏点可以鼓励绕路，但不能要求玩家穿过不可通行边界。
- `Z` 遇敌区不得覆盖出生营地中心、前哨中心、桥面和恢复点中心。
- 所有视觉死路尽头都应有理由：道具、隐藏点、景观、稀有遇敌或未来入口。

软门槛设计：

| 门槛 | 实现方式 | 目的 |
|---|---|---|
| 旧图到新图 | 地形引导，不强制锁 | 让老玩家自然发现扩展区域 |
| 湿地到前哨 | `B1` 桥和道路收束 | 强化第一次进入新章节的仪式感 |
| Boss 前 | `B2` 桥、岩场和部下解锁提示 | 明确“还没准备好”的信号 |
| Boss 后 | `tier_3` 稀有草丛、隐藏道具、后续入口 | 保留通关后的探索价值 |

### 5.6 V6.5 专业地图设计审查

本节按专业游戏地图设计师视角审查当前方案。目标不是继续堆内容，而是保证玩家能读懂路线、理解目标、愿意探索，并且地图实现后不会因为拥堵、碰撞、节奏或素材风格失控而变得难玩。

总体判断：

- 当前方案已经从“单线推进地图”升级为“章节主线 + 多环线探索 + 隐藏微区域”的结构，探索密度足够。
- 下一阶段最大风险不再是内容少，而是信息过载、局部拥堵、视觉主题失控和实现层不能准确承接文档规划。
- 第一版执行时必须克制，只落地核心白盒、关键地标、8 个隐藏点和必要玩法点；完整素材密度应等白盒验证通过后再加。

风险与优化方向：

| 风险 | 位置 | 问题 | 影响 | 优化方向 |
|---|---|---|---|---|
| `R1` 前哨过载 | `O(48,47)` 周边 | 前哨承接主路、采木、湿地、农田、NPC、补给和任务提示 | 玩家刚到章节中心时容易视觉拥堵，NPC 或箱桶可能堵路 | 做 `8x8` 安全广场；NPC、摊位、箱桶全部放外圈；中心只保留路牌/目标提示 |
| `R2` 湿地桥头拥堵 | `B1(61,33)` 周边 | 主路、Z05、湿地栈道、HS05、桥位聚在一起 | 可能出现桥头触发遇敌、装饰挡桥或玩家看不清去向 | 桥头前后 `3` 格清空；Z05 从桥面扣除；芦苇暗道入口放桥东侧，不压桥口 |
| `R3` Boss 入口识别不足 | `B2(88,62)` 到 Boss | B2、T5、Z12/18、矿洞、Boss 侧门信息密集 | Boss 前门槛不清，玩家可能误入后段高压区 | 用岩门、废轨、金属围栏形成“挑战门”；Boss 路线用更暗更密的素材渐进 |
| `R4` 旧图接缝感 | A 到 C/G 出口 | 旧 `44x36` 与新增区域气质差异大 | 扩图可能像外挂拼接，不像自然世界延伸 | 在旧东口和旧南口做过渡地标：石路边、路牌、矮围栏、花坡/木桩渐变 |
| `R5` 东岸主题抢戏 | E 东岸海湾 | `pirate-kit` 素材强辨识，容易把地图变成海盗主题 | 宝可梦生态被船、旗、炮压过 | 船、码头、桶瓶只贴水岸；海盗旗和炮限量；内陆只保留沙石和棕榈边界 |
| `R6` 河口功能叠加 | J 河口钓营 | H、C、B3、Z11、沙洲隐藏点距离近 | 恢复点、连战、遇敌和桥位节奏可能互相打断 | H 中心做安全圈；C 前后留对话区；Z11 从恢复点和桥位扣除 |
| `R7` 生态合法性 | Z01-Z18 | 遇敌表、等级、进化上限、隐藏池隔离都依赖代码审计 | 可能出现有草丛但抽不到、或三御家/奖励池误入普通野生 | 扩表前先修 `wildEncounterRules`；新增自动审计脚本；每区抽样 50 次 |
| `R8` 素材性能与显示 | 全图素材层 | 完整视觉版 320-420 实例，且新增素材不在项目资源目录 | 可能出现 404、黑模、卡顿、碰撞不准 | 先接入 60-90 个别名；按模型 instancing；大型素材必须有 footprint |

专业优化建议：

- 主线视觉层级必须高于支路：主路更宽、更亮、更连续；支路更窄、更碎；隐藏路只用素材暗示。
- 每个环线都要有一个“记忆点”：北山脊是水车/瀑布，湿地是月镜小岛，东岸是船骸，采木是树桩迷径，幽林是灯笼铁栅，农田是稻草人，河口是沙洲，废场是控制台。
- 奖励盲端不要超过 `14` 格；超过就改成环线，否则玩家会觉得被惩罚。
- 前 10 分钟不能让玩家同时面对太多锁定内容。`HS06/HS07/HS13/HS14` 应作为中后期或 Boss 后伏笔，不在初期强提示。
- 遇敌区应像生态斑块，不像矩形触发器。执行时优先用多个小草丛合并，而不是一整块大矩形。
- `O` 前哨、`H` 恢复点、`B2` Boss 门槛是三个节奏锚点，必须留白，不能被素材密度目标绑架。
- 素材风格混搭要有“因果”：fantasy town 表示人类定居，graveyard 表示旧遗迹，pirate 表示水岸生活，platformer 表示地形高差/废场，不要跨语境乱摆。
- 第一版地图评审应该先看灰盒可达性和路线可读性，再看美术丰富度。视觉丰富但路线不清，是失败地图。

#### 5.7.5 总监视角的优化结论

当前地图规划已经具备“章节地图”的完整骨架，但真正执行时要警惕三个方向：

- `可读性优先于丰富度`：支路、隐藏、素材已经足够多，第一版最怕把它们一次铺满导致玩家看不懂主线。
- `留白也是设计`：`O` 前哨、`H` 恢复点、`B1/B2/B3` 桥头不是空旷问题，而是节奏安全区。这里越干净，地图越专业。
- `素材必须服从生态和因果`：`fantasy-town` 表示定居，`survival` 表示野外生存，`pirate` 表示水岸，`graveyard` 表示旧遗迹，`platformer` 表示高差/废场，`hexagon` 表示远景地标。素材跨语境使用会破坏地图可信度。
- `隐藏要可推理`：隐藏点不能像 bug。玩家应该能通过灯笼、花环、破栅栏、异色草、浅滩石、船骸舱口这类视觉异常推断“那里可以查”。
- `遇敌像生态斑块，不像矩形触发器`：执行时应由多个草丛/泥滩/水边小块组成，不要整片矩形覆盖道路。
- `Boss 前要有心理门槛`：`B2` 后的岩门和废轨要让玩家直觉知道“这里是章节高潮”，而不是普通支路。
- `回访理由要后置`：`HS13/HS14/Z18/W` 这些后续内容第一版可以作为伏笔，但不要提前开放未完成玩法。

执行优先级建议：

1. 先落白盒地形、水体、主路、`BR01-BR08` 和桥位。
2. 再做可达性、桥头净空、安全圈和边缘封闭。
3. 再接 `Z01-Z18` 遇敌生态，并先修 `wildEncounterRules` 的等级上限风险。
4. 再落 `M01-M16` 的核心玩法点，其中隐藏点先做 `HS01/HS03/HS04/HS05/HS08/HS09/HS11/HS12`。
5. 最后分批接素材，第一批只接高确定性 `60-90` 个别名，跑 404、尺度、碰撞、帧率验收后再扩充。

#### 5.8.6 遇敌与安全旅行带

顶级地图设计里，野生遇敌不是“覆盖地图的随机打断”，而是生态压力。V6.7 要求每个 `Z` 区执行时扣出安全旅行带：

- 主路中心线左右至少 `1-2` 格不触发随机遇敌。
- 桥面、桥头前后 `3` 格、前哨中心、恢复点中心、Boss 开战点全部从遇敌区扣除。
- 稀有层 `Z15-Z18` 只在进度或 Boss 后增强，不进入普通随机池。
- 生态区以草丛、泥滩、芦苇、水边、碎石、废料堆等斑块出现，不做整片矩形触发器。
- 玩家主动离开主路进入草带/浅滩/废场时，才获得更高遇敌密度和更好奖励。

#### 5.8.8 V6.7 落地优先级

#### 5.9.3 遇敌解锁的修正口径

为了避免“目标在高阶区，但高阶区要打完目标才开”的死锁，V6.8 采用“通路和草丛分离”的口径：

| 区域 | 通路 | 普通草丛 | 稀有/深处层 |
|---|---|---|---|
| `Z04` 北山脊 | 到 `G1` 的石花坡/山脚通路 `tier_0` 可达 | 北山脊普通岩草 `tier_1` | `Z15` 草窝和幼基拉斯极低概率 `tier_1+` |
| `Z09` 幽林 | 到 `G2` 的灯笼主径 `tier_1` 可达 | 外圈鬼斯/催眠貘/臭泥 `tier_1` | 鬼斯通/勇基拉 `tier_2`，引梦貘人 `tier_3` |
| `Z11` 河口 | 到 `H/B3` 的营地路 `tier_0` 可达 | 水边基础生态 `tier_1` | 暴鲤龙强生态或高阶水边 `tier_2+` |
| `Z18` 岩洞口 | `B2` 到 Boss 的挑战路 `tier_2` 可达 | 岩洞口压力层 `tier_2` | Boss 后稀有层 `tier_3` |

执行时不要把 `encounterZone` 等同于“物理可达区域”。同一个地理区域可以有安全通路、普通草带和稀有草窝三层。

#### 5.9.4 奖励经济审计

地图奖励不能只看“给了什么”，还要看它会不会破坏升级曲线、经验药水弹窗、进化节奏和战斗平衡。

V6.8 奖励预算：

| 奖励类型 | 第一版上限 | 说明 |
|---|---:|---|
| 小型经验药水 | `4-6` | 用于隐藏教学和支路奖励，不在主路连续投放 |
| 中型经验药水 | `1-2` | 只给部下后、连战后或 Boss 前补给 |
| 超级球 | `4-6` | 支持新生态捕捉，但不让玩家无限滚雪球 |
| 好伤药 | `3-5` | Boss 前和远支路给少量 |
| 固定宝可梦奖励 | `0-1` | 第一版尽量不放，避免破坏图鉴获得节奏 |
| 当前无用途进化道具 | `0` | `日之石`、`王者之证`、`金属膜` 不投放 |

经验药水必须触发升级/进化弹窗，并展示新旧参数对比；如果经验超过升级阈值但没有升级，要优先排查经验结算和升级循环，而不是继续加奖励。

#### 5.9.5 执行一致性守则

后续真正改代码时，按这几个守则判断是否偏离设计：

- 如果一个点会让玩家跳过 `O` 前哨的目标说明，它必须被软引导回 O。
- 如果一个训练师是 Boss 解锁条件，它所在通路不能依赖击败其他全部部下后才开放。
- 如果一个区域是恢复、桥头、Boss 门槛或前哨中心，它优先是安全空间，不是素材展示区。
- 如果一个素材包的主题强到玩家会误读地图类型，就把它降为可选支路主题。
- 如果一个奖励会明显改变升级或进化节奏，就先进入奖励预算表，不直接投放。
- 如果一个后续入口没有对应玩法，就只做远景伏笔，不做可交互入口。

### 6.2 素材接入流程

落地前先做资产盘点，不要直接在地图数据里猜文件名。

步骤：

1. 枚举 `public/assets`、项目已有 Kenney 目录，以及下载目录中的 `kenney_survival-kit`、`kenney_fantasy-town-kit_2`、`kenney_graveyard-kit_5`、`kenney_platformer-kit`、`kenney_blocky-characters_20`、`kenney_pirate-kit`、`kenney_hexagon-kit`。
2. 从所有素材包中先选出 `60-90` 个高确定性别名，第一版只接入这些；其他模型保留为后续视觉扩展，不一次性全塞进运行时。
3. 建立素材别名表，例如 `town_stall_green`、`shore_dock_small`、`grave_lantern_glass`、`ridge_block_grass_edge`、`npc_fisher_a`。
4. 将选定 GLB 复制或缓存到 `public/assets/3d/kenney-*`，在 `ThreeLowPolyMap.jsx` 或后续 `mapAssetRegistry.js` 中注册 URL。
5. 在地图数据中优先使用别名，别名再映射到具体模型、图片或低模对象。
6. 给每类素材标记 `blocking`、`decorativeOnly`、`heightClass`、`themeTags`、`allowedAreas`、`footprint`。
7. 大型素材先落碰撞，再落装饰；小型填充素材默认不挡路，除非明确是岩壁、树干、围栏、建筑、箱堆。
8. 新增模型接入后先跑本地浏览器检查，确认没有 404、黑模、尺度过大、遮挡主路、移动端卡顿。

建议素材清单字段：

```js
{
  id: 'shore_dock_small',

  source: 'kenney_pirate-kit',

}
```

| 类型 | 默认碰撞 | 可放位置 | 不可放位置 |

| 帐篷、工作台、箱堆 | 是 | 前哨外圈、营地外圈 | NPC 面前 1 格、恢复点中心 |
| 桶瓶、草簇、小蘑菇 | 否 | 路边、水边、田边 | 交互点正上方 |
| 围栏、木桩、金属板 | 视尺寸 | 农田边界、废场边界 | 唯一路径窄口 |
| 栈道、桥、浅滩石 | 否或特殊 | 水边和桥位 | 深水无连接处 |

### 7.2 隐藏、奖励与后续预留池

以下宝可梦不进入普通随机遇敌，但需要在设计上保留“去处”。这样玩家会感觉图鉴是有计划地展开，而不是遗漏。

| 类别 | 宝可梦 | 建议获得方式 | 是否本地图第一版实现 |
|---|---|---|---|
| 开局/老师奖励 | 妙蛙种子、小火龙、杰尼龟 | 开局选择、老师奖励、任务兑换 | 沿用现有机制，不放野外 |
| 睡眠道路事件 | 卡比兽、小卡比兽 | 食物任务、道路阻挡事件 | 第二版或后续章节 |
| 水边救援 | 拉普拉斯、白海狮 | 河口救援、寒潭支线 | 预留，不进随机表 |
| 化石研究 | 化石翼龙、菊石兽、化石盔 | 岩洞化石碎片、研究员复原 | 岩洞后续支线 |
| 数据修复 | 3D龙、多边兽II、多边兽Z | 金属废场数据终端、修复任务 | `tier_3` 后可预留入口 |
| 龙潭奖励 | 迷你龙、哈克龙、快龙 | 秘密龙潭、单次奖励、成长进化 | 不进普通随机 |

| 传说/幻 | 火焰鸟、急冻鸟、闪电鸟、超梦、梦幻 | 后续大章节或特殊活动 | 本地图只做伏笔，不投放 |

当前玩法中没有明确用途的道具不要硬塞进地图奖励，尤其是 `日之石`、`王者之证`、`金属膜` 这类暂时无法形成闭环的道具。若未来接入相应进化或任务，再补到对应支线。

隐藏奖励原则：

- 第一版隐藏奖励以球、药水、经验药水、线索牌为主。
- 稀有宝可梦奖励必须有剧情或挑战门槛，不直接藏在普通草丛。
- 固定奖励只能领取一次，必须写入 `mapProgress`。
- 奖励宝可梦的等级应接近玩家当时队伍均级，不能破坏前中期战斗平衡。

## 8. 野生遇敌进度档位

迷雾森林建议 `4` 档：

| 档位 | 名称 | 解锁条件 | 效果 |
|---|---|---|---|
| `tier_0` | 初探森林 | 默认 | 低等级基础生态 |
| `tier_1` | 试炼升温 | 击败任意 1 名部下 | 等级略升，部分少见物种解锁 |
| `tier_2` | 迷雾渐散 | 击败 3 名部下 | Boss 解锁，区域表加入中段生态 |
| `tier_3` | 首领余威 | 击败 Boss | Boss 后稀有草丛和稀有权重启用 |

等级偏移：

| 档位 | min 偏移 | max 偏移 | 不超过队伍均级 |
|---|---:|---:|---:|
| `tier_0` | +0 | +0 | `playerAvg + 3` |
| `tier_1` | +1 | +2 | `playerAvg + 4` |
| `tier_2` | +2 | +4 | `playerAvg + 5` |
| `tier_3` | +3 | +5 | `playerAvg + 6` |

实现建议：

- 新增 `src/game/data/mapGameplay.js` 保存 `MAP_ENCOUNTER_TIERS` 和 `MAP_ENCOUNTER_PATCHES`。
- 新增 `src/game/mapEncounterProgress.js` 或同等模块，提供 `getMapEncounterTier()`、`buildEffectiveEncounterTable()`、`pickWildPokemonForMap()`。
- `ThreeLowPolyMap.jsx` 和 `EncounterSystem.js` 不再直接调用 `pickWildPokemon(tableId)`，而是传入 `mapId + zone + mapProgress + playerTeam`。

### 8.1 遇敌合法性与平衡审计

执行区域遇敌表前，必须先做自动审计。审计失败时不要继续铺地图，否则会出现“看似有草丛，实际抽不到合法宝可梦”的问题。

每张遇敌表必须满足：

- 至少 `5` 个候选物种。
- 权重总和大于 `0`，且稀有物种总权重不超过 `12`。
- 每个物种 ID 必须存在于 `MONSTERS`。
- 每个等级范围必须满足 `min <= max`。
- 等级范围必须与 `getSpeciesLevelBounds()` 的合法上限相交。
- 不允许把隐藏/奖励/传说/进化专属池误放进普通随机表。
- `tier_0` 表不得出现明显高阶压制物种，例如最终形态、准神后段、高阶电/钢/毒。

建议输出审计报告：

| 检查项 | 通过标准 |
|---|---|
| 图鉴覆盖 | 144 只全部能归入随机野生、隐藏奖励或进化专属 |
| 表可抽取 | 每张表至少有 5 个在当前等级下可抽到 |
| 阶段上限 | 无 `max: -1`，无 `max < min` |
| 生态一致 | 水区主要是水边生态，废场主要是电/钢/毒，岩场主要是岩/地面/格斗 |
| 稀有控制 | 幼基拉斯、沙基拉斯、吉利蛋、袋兽等低概率，不污染常见池 |

等级动态规则：

- 实际野生等级取 `表基础等级 + tier 偏移`，再受 `playerAvg + 档位上限` 限制。
- 若玩家队伍等级过低，允许轻微下调野生等级，但不要低于该区域基础下限太多。
- Boss 后 `tier_3` 可以提高稀有层权重，但不应把所有区域都变成高等级区，旧图和新手草坡仍应保持教学价值。

## 9. 章节玩法

章节名建议：**迷雾森林试炼**。

主线流程：

1. 玩家从旧出生营地 `S` 出发。
2. 通过旧东口进入石花坡和月镜湿地。
3. 到达生存补给前哨 `O`，获得章节目标提示。
4. 击败三名部下 `G1/G2/G3`。
5. Boss 迷雾首领 `B` 解锁。
6. 挑战 Boss。
7. Boss 后解锁稀有草丛、隐藏道具、再战或后续地图入口。

### 9.1 部下训练师

| ID | 标记 | 区域 | 主题 | 队伍数量 |
|---|---|---|---|---:|
| `guard_ridge` | `G1` | 北山脊/石花坡交界 | 高地生态检查与新地图探索引导 | 3 |
| `guard_grove` | `G2` | 蘑菇幽林 | 幽林和状态战 | 3 |
| `guard_lake` | `G3` | 湿地/湖岸 | 水系与控制 | 3 |

击败 1 名部下后升到 `tier_1`。击败 3 名后升到 `tier_2` 并解锁 Boss。

### 9.2 普通训练师

建议 6 名：

| 标记 | 区域 | 作用 |
|---|---|---|
| `T1` | 采木高地入口 | 低中等级战斗 |
| `T2` | 虫林边缘 | 引导支路探索 |
| `T3` | 东岸码头 | 水边主题战斗 |
| `T4` | 农田边界 | 农田生态战斗 |
| `T5` | 岩洞口 | Boss 前预热 |
| `T6` | 山脊小径 | 瀑布源提示 |

普通训练师不影响 Boss 解锁，但计入探索完成度。

### 9.3 Boss

Boss ID：`mist_boss`  
位置：岩场与金属废场深处 `B`。  
解锁：击败 `guard_ridge`、`guard_grove`、`guard_lake`。  
队伍：6 只，等级高于部下。  
奖励：高级球、好伤药、经验药水、地图完成标记，后续可加隐藏宝可梦或稀有草丛。

### 9.4 连战挑战

位置：河口与农田之间 `C`。  
规则：

- 玩家主动选择开始。
- 按地图难度递进为 `3 / 4 / 5 / 6` 连战，最高只允许 `6` 连战。
- 中途失败无奖励，可重试。
- 首次胜利给随区域难度递增的经验药水、精灵球和回复药。
- 首次胜利永久写入 `completedChallengeIds`，奖励和隐藏生态不随每日刷新重复解锁。
- 试炼隐藏生态只放入符合本区域等级上限的非传说/幻宝可梦；三圣鸟、超梦、梦幻保留为后续隐藏剧情或特殊奖励。

### 9.5 恢复点

位置：河口钓营 `H`。  
规则：

- 每次进入地图可用 1 次。
- Boss 解锁后可额外恢复 1 次。
- 使用状态保存到 `mapProgress.usedHealPointIds`。

### 9.6 道具与隐藏点

建议第一版：

- 可见道具：8-10 个。
- 隐藏点：第一版不少于 8 个，完整设计保留 14 个隐藏微区域。
- Boss 前补给：好伤药、超级球、小型经验药水。

道具类型：

- 精灵球、超级球。
- 伤药、好伤药。
- 小/中经验药水。
- 隐藏任务道具或线索牌。

隐藏点放置逻辑：

- 石头后面。
- 树桩旁。
- 花丛中心。
- 湿地栈道末端。
- 岔路尽头。
- 金属废场角落。

### 9.7 战斗触发与文字节奏

地图事件进入战斗时，节奏要给玩家读文字的时间，尤其是训练师、Boss、连战挑战和稀有野生遭遇。

触发规则：

- 普通野生遇敌：进入战斗前显示简短遭遇提示。
- 固定训练师：先锁定玩家移动，再播放 1-2 句对话，再进入战斗。
- Boss：必须有解锁状态判断；未解锁时只显示提示，不开战。
- 连战挑战：开始前二次确认，失败后返回挑战点附近，不直接连续弹下一场。
- 隐藏奖励宝可梦：应显示发现提示、奖励来源和是否加入队伍/仓库。

播报节奏建议：

| 场景 | 最短停留 | 说明 |
|---|---:|---|
| 野生遭遇提示 | `700-900ms` | 让玩家知道遇到了什么 |
| 训练师开战台词 | `1000-1400ms` | 允许玩家读完一句短台词 |
| Boss 解锁/未解锁提示 | `1200-1600ms` | 章节关键信息不能一闪而过 |
| 获得道具/隐藏点提示 | `900-1200ms` | 避免玩家不知道拿到了什么 |
| 连战场次切换 | `1200-1800ms` | 每场之间留出心理缓冲 |

交互保护：

- 同一事件触发后，在弹窗或战斗开始前应进入短暂 `interactionLock`。
- 文字播报期间不要重复响应移动键导致重复触发。
- 战斗结束返回地图时，玩家应短暂无敌或延迟遇敌 `1-2` 秒，避免刚退出战斗又立刻进战斗。
- 训练师和 Boss 的已击败状态必须先写入存档，再恢复地图控制。
