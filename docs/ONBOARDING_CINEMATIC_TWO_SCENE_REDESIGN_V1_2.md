# 新手流程电影式双段重设计 V1.2

> 本版只做设计，不改运行代码。  
> 方向：删除当前“信标第一幕”这个界面步骤，只保留“伙伴共鸣”和“山谷启程”两个核心段落。整体不再像 UI 向导，而像一段给学生看的动画短片：画面、台词、过场镜头、少量自然交互。

可视化故事板：[`docs/onboarding-cinematic-two-scene-v1.2.svg`](./onboarding-cinematic-two-scene-v1.2.svg)

---

## 1. 核心改动

### 删除什么

未来执行时删除独立的第一幕：

- 不再出现 `信标` 进度按钮。
- 不再出现像功能页一样的“课堂表现 / 日常练琴 / 老师奖励 / 冒险成长”四宫格说明。
- 不再让学生先看一页“系统如何同步、老师如何奖励”的界面。

### 保留什么

只保留两个电影段落：

| 段落 | 原对应 | 新呈现 |
|---|---|---|
| 伙伴共鸣 | 原第二幕 | 五只伙伴在音乐星光中依次入镜，学生通过点击/触摸画面里的宝可梦完成选择 |
| 山谷启程 | 原第三幕 | 老师奖励化作光轨进入背包，伙伴牵引镜头降落新手山谷 |

### 老师奖励如何解释

不单独做“信标第一幕”，而是在镜头里自然讲：

```text
课堂表现 + 日常练琴
        ↓
老师看见并发放奖励
        ↓
能量挑战 / 金币 / 补给 / 惊喜
        ↓
伙伴获得继续冒险的准备
```

这条因果线必须被学生看懂，但不能像规则说明页。它要通过琴键、音符、老师剪影、奖励光轨、伙伴回应来表达。

## 2. 体验目标

- **像动画片**：开场是镜头，不是表格；台词是旁白，不是说明卡。
- **像电影过场**：有镜头运动、景深层次、黑场转场、字幕和角色回应。
- **没有按钮感**：不出现大块矩形按钮；必要操作通过画面中的对象完成。
- **学生能理解现实关联**：课堂认真、日常练琴、老师奖励和游戏冒险之间的关系必须直观。
- **仍然可玩**：伙伴选择必须明确，进入地图前不能拖太久。

建议时长：

| 段落 | 时长 |
|---|---:|
| 伙伴共鸣 | 55 到 75 秒 |
| 山谷启程 | 35 到 55 秒 |
| 总计 | 90 到 130 秒，可跳过、可快进 |

---

## 3. 视觉总风格

### 画面结构

使用全屏电影画幅：

- 顶部和底部轻微暗角，像动画片过场。
- 字幕在底部，不放在卡片里。
- 关键信息用画面符号表达：琴键、音符、老师徽章、奖励光轨、背包、伙伴脚步、山谷路牌。
- 交互提示极轻：`轻触回应你的伙伴`，像字幕，不像按钮。

### 不要出现的东西

- 不要五步进度条。
- 不要四宫格规则说明。
- 不要“下一步 / 上一步”这种强 UI 按钮感。
- 不要大块白色卡片堆叠。
- 不要把奖励做成抽奖开箱视觉，避免误解为赌博式刺激。

### 可以保留的必要交互

为了游戏能进行，仍需要交互，但视觉上应藏在画面里：

| 操作 | 呈现方式 |
|---|---|
| 选择伙伴 | 点击/触摸画面中的宝可梦本体或剪影 |
| 确认伙伴 | 选中后伙伴走近镜头，字幕出现“如果是你，我愿意一起走。”再轻触伙伴确认 |
| 跳过过场 | 角落小字 `长按跳过`，不是显眼按钮 |
| 进入山谷 | 伙伴转身跑向山谷道路，玩家轻触道路光点进入 |

## 4. 故事线

故事主题：

> 不是游戏凭空奖励你，而是你现实里的努力被老师看见，然后变成伙伴能感受到的星光。

### 故事梗概

钢琴教室里，一次认真上课留下了一串发光音符。晚上，日常练琴的音符从练习本上升起，与课堂中的星光汇合。老师的徽章轻轻亮起，奖励光轨打开，能量、金币、补给和一个未打开的惊喜光点飞向远处的宝可梦世界。

五只初始伙伴在星光中醒来。它们不是摆在按钮上等玩家挑选，而是分别用动作回应学生：小火龙举起尾焰，妙蛙种子背上的种子发光，杰尼龟拍了拍龟壳，皮卡丘带着电光跑近，伊布安静地抬头。学生轻触回应自己的伙伴。

伙伴确认后，镜头不切回界面，而是跟着伙伴奔向新手山谷。老师奖励的光点化作背包补给，落在营地旁。路牌亮起，第一片草丛轻轻晃动，山谷远处传来水声，冒险开始。

## 5. 分镜设计

## 段落 A：伙伴共鸣

### A1. 教室里的第一束光

| 项目 | 设计 |
|---|---|
| 画面 | 暖色钢琴教室，琴键近景，谱架上有一枚星音徽章 |
| 镜头 | 低角度推近琴键，指尖落下时出现第一颗蓝金色音符 |
| 动画 | 琴键轻压，音符从琴弦一样的光线中飞起 |
| 台词 | `旁白：每一次认真上课，都会留下回声。` |
| 学生理解 | 课堂表现会被记录 |

### A2. 日常练琴的夜光

| 项目 | 设计 |
|---|---|
| 画面 | 练琴日历翻页，几天练习记录变成连续光点 |
| 镜头 | 从练习本横移到窗外夜空 |
| 动画 | 每个练习记录亮一下，连成一条稳定的星线 |
| 台词 | `旁白：每天练琴留下的音符，会让这束光更稳定。` |
| 学生理解 | 坚持练琴会让奖励和成长更稳定 |

### A3. 老师点亮奖励光轨

| 项目 | 设计 |
|---|---|
| 画面 | 老师剪影在谱架旁抬手，星音徽章亮起 |
| 镜头 | 老师不需要露脸，重点是“老师看见表现” |
| 动画 | 四个奖励符号沿光轨飞出：能量闪电、金币、补给包、惊喜星点 |
| 台词 | `星音导师：当你的表现足够亮，我可以把它变成能量、金币、补给，甚至特别惊喜。` |
| 学生理解 | 老师可以根据课堂和练琴表现发奖励 |

### A4. 五只伙伴醒来

| 项目 | 设计 |
|---|---|
| 画面 | 星光落在五个小舞台，五只伙伴依次入镜 |
| 镜头 | 从左到右滑动，但每只伙伴都有独立 2 秒小表演 |
| 动画 | 火光、叶光、水纹、电光、星点分别出现 |
| 台词 | `旁白：这些光，会被愿意陪你冒险的伙伴听见。` |
| 学生理解 | 现实努力和伙伴选择产生连接 |

### A5. 选择伙伴

| 项目 | 设计 |
|---|---|
| 画面 | 五只伙伴站在同一片星光草地，不是五个按钮 |
| 镜头 | 被触摸的伙伴走近镜头，其他伙伴退到柔光里 |
| 动画 | 选中伙伴有专属回应动画 |
| 字幕 | `轻触回应你的伙伴` |
| 交互 | 点击宝可梦本体选择；再次轻触走近的伙伴确认 |

伙伴专属台词：

| 宝可梦 | 选中台词 | 镜头动作 |
|---|---|---|
| 小火龙 | `它把尾焰举高，像是在说：往前走，我跟得上。` | 火光照亮前路 |
| 妙蛙种子 | `它安静地靠近你，背上的种子泛起柔和绿光。` | 草叶在脚边展开 |
| 杰尼龟 | `它拍了拍龟壳，认真地点了点头。` | 水纹护盾扩散 |
| 皮卡丘 | `电光一闪，它已经跑到你的脚边。` | 镜头快速跟随电光 |
| 伊布 | `它歪头看着你，像在等待一个共同决定的未来。` | 星点围绕尾巴 |

## 段落 B：山谷启程

### B1. 奖励落入背包

| 项目 | 设计 |
|---|---|
| 画面 | 选中伙伴转身，老师奖励的光点追上来 |
| 镜头 | 跟拍伙伴背影，奖励光点从画面左上滑入 |
| 动画 | 能量、金币、补给、惊喜星点依次落入背包 |
| 台词 | `星音导师：这些不是凭空出现的奖励，它们来自你真实完成的努力。` |
| 学生理解 | 游戏资源来自现实学习表现，不是随便送 |

奖励字幕：

```text
能量：让你继续挑战。
金币：帮你准备冒险补给。
补给：在关键时刻保护伙伴。
惊喜：稳定练习时，也许会点亮特别线索。
```

### B2. 镜头穿过云层

| 项目 | 设计 |
|---|---|
| 画面 | 镜头跟着伙伴和星光穿过云层，远处出现新手山谷 |
| 镜头 | 俯冲式下降，从天空到营地 |
| 动画 | 山谷路牌、营火、草丛依次亮起 |
| 台词 | `旁白：第一条路已经亮起。` |
| 学生理解 | 进入正式冒险 |

### B3. 营地落地

| 项目 | 设计 |
|---|---|
| 画面 | 伙伴落在营地旁，回头看玩家 |
| 镜头 | 从伙伴脚边抬升到路牌，再移向草丛 |
| 动画 | 路牌轻亮，第一片草丛晃动 |
| 台词 | `星音导师：先看路牌，再进入草丛。你的第一场野外练习，就从这里开始。` |
| 学生理解 | 明确第一步怎么玩 |

### B4. 无按钮进入地图

| 项目 | 设计 |
|---|---|
| 画面 | 土路上出现一个自然的光点，不是按钮 |
| 字幕 | `轻触发光的小路，进入新手山谷` |
| 交互 | 点击光点后进入真实地图 |
| 过渡 | 光点扩大为白场，再淡入 3D 地图 |

## 8. 验收标准

- 第一眼看起来像动画过场，不像登录页、设置页或教学弹窗。
- 没有可见的进度条和大按钮。
- 学生能看懂：课堂表现和日常练琴会影响老师可发放的能量、金币、补给和惊喜。
- 伙伴选择有仪式感，每只伙伴都像角色，而不是商品卡片。
- 山谷启程能清楚告诉学生第一步：看路牌、进草丛。
- 可跳过、可快进，但首次观看不显得廉价或敷衍。
- 不展示当前玩法没有用途的道具，例如日之石、王者之证、金属膜。
