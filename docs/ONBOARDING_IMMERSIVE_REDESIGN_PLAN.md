# 新手流程沉浸式重设计方案 V1.1

> 目标：把当前“功能说明式启动向导”重做成一个像动画短片一样的新手章节。学生要在故事里自然理解：课堂表现和日常练琴会被老师看见，并转化为能量、挑战机会、金币和更多游戏内惊喜。  
> 本文先作为设计稿与执行蓝图，不直接改动运行逻辑，确认后再进入代码实现。

可视化设计稿：[`docs/onboarding-immersive-flow-v1.svg`](./onboarding-immersive-flow-v1.svg)

---

## 1. 设计结论

当前新手流程的核心问题不是数据缺失，而是体验顺序像“设置清单”：

- `邀请 → 档案 → 伙伴 → 补给 → 启程` 五步都在解释系统，玩家还没进入世界就被迫读功能说明。
- 伙伴选择已有视觉基础，但缺少“宝可梦回应玩家”的角色表演。
- 补给、云端档案、老师奖励这些重要机制讲得太直白，像后台说明，不像故事。
- 启程后只有战斗日志提示，地图内没有持续的新手目标、镜头反馈和第一次草丛事件。

建议把新手流程升级为 **可跳过的动画短片式序章 + 3 幕互动启动页 + 3 到 5 分钟地图内微剧情**。核心不是减少说明，而是把说明变成画面、台词和奖励因果：

| 段落 | 玩家感受 | 核心操作 | 系统信息的隐藏方式 |
|---|---|---|---|
| 动画序章：练琴回声 | 我现实里的练习正在点亮游戏世界 | 观看，可跳过 | 课堂表现、日常练琴、老师奖励通过动画因果讲清楚 |
| 第一幕：信标呼唤 | 我被研究所召唤进入冒险 | 回应信标 | 云端档案、老师奖励通道包装为“星音信标接入” |
| 第二幕：伙伴共鸣 | 宝可梦正在选择我，我也在选择它 | 选择初始伙伴 | 属性、定位、成长方向通过伙伴台词和短标签展示 |
| 第三幕：山谷启程 | 我带着伙伴和补给降落到营地 | 确认启程 | 背包道具、目的地、草丛规则通过动画和地图预览展示 |
| 地图微剧情 | 我知道第一步该做什么，并马上遇到事件 | 看路牌、进草丛、第一次遭遇 | 移动、互动、遇敌、捕捉在场景中自然发生 |

### 1.1 教育激励闭环

学生必须在第一分钟内看懂这条因果线：

```text
课堂认真表现 / 每日练琴记录
        ↓
老师在后台发放奖励
        ↓
能量用于继续挑战，金币用于购买补给
        ↓
惊喜奖励可能带来稀有道具、经验药水、捕捉机会或后续隐藏线索
        ↓
现实练习越稳定，冒险推进越顺利，伙伴成长越明显
```

呈现原则：

- **不说教**：不写“你应该练琴”，而是让画面显示练琴音符变成星光，星光进入研究所奖励管道。
- **不空承诺**：当前系统已经有金币、能量、背包道具、经验药水、捕捉资源，惊喜奖励优先落在这些已存在类型上。
- **可扩展**：未来若加入称号、头像框、隐藏地图钥匙、限定伙伴线索，也可以放进“惊喜奖励”池。
- **老师存在感强**：老师不是后台按钮，而是故事里的“星音导师”，会根据课堂和练琴表现点亮信标。
- **学生能复述**：看完后学生应该能说出“我好好上课和练琴，老师就能给我能量、金币或惊喜，我就能继续挑战和培养宝可梦”。

| 位置 | 现状 | 新设计改动点 | 主要风险 |
|---|---|---|---|

| `handleStartGame` | 创建 Lv.5 伙伴，写入 3 条日志 | 增加新手任务初始状态、沉浸式日志、地图目标提示 | 当前 `currentGameData` 没有把 `world.flags` 作为独立 React state 传入快照，贸然加 flag 可能无法持久化 |
| `src/index.css` `.launch-*` | 有基础卡片、天空线条、伙伴面板 | 新增幕间转场、伙伴呼吸、选择反馈、补给飞入、地图路径点亮 | 动画不能太重，需支持 `prefers-reduced-motion` |
| `src/game/data/godotMaps/my_first_map.js` | 营地、路牌、草丛已存在 | 不改变现有地图，只把出生营地、路牌、第一草丛作为任务锚点 | 未来 100x100 扩图时锚点需迁移或保留兼容 |
| `src/game/data/mapEvents.js` | `getMapEvents()` 目前返回空数组 | 后续可加入新手任务事件配置 | 事件 ID、已完成状态、旧存档兼容需要先设计 |
| `handleCollect(type='info')` | 路牌只弹通知 | 新手期间读路牌要推进任务、触发下一目标 | 不能让老玩家重复触发新手任务 |
| `handleEncounter` | 草丛随机遇敌 | 新手第一次草丛可引导一次低压遭遇 | 不能破坏随机遇敌、冷却、逃跑和捕捉流程 |

## 3. 新手体验曲线

目标时长：第一次进入到完成首个草丛事件约 **4 到 6 分钟**，其中动画序章建议 **45 到 75 秒**，可跳过。  
目标点击：进入地图前不超过 **3 次主要确认**。  
目标阅读量：每屏主文案不超过 **2 行**，但允许用分镜、短字幕和画面符号充分说明“练琴表现 → 老师奖励 → 冒险成长”的因果。

```text
0:00  动画序章：教室钢琴声响起，音符变成星光
0:15  日常练琴日记翻页，连续练习点亮星音信标
0:30  老师奖励通道开启：能量、金币、补给和惊喜箱进入研究所
0:50  研究所信标亮起，玩家回应
1:10  五只伙伴出现，玩家选择第一位伙伴
1:50  伙伴回应，补给入包，路径点亮
2:10  降落新手山谷营地
2:30  读营地路牌
3:00  前往第一片草丛
3:20  第一次野生遭遇
4:20  捕捉 / 击败 / 逃跑后完成第一目标
4:50  远处道路亮起，埋下后续地图探索伏笔
```

## 4. 动画序章与启动页三幕设计

### 4.0 动画序章：练琴回声

**定位**

这是整个新手流程最重要的教育叙事：让学生感到“我现实里的努力，会在宝可梦世界里被看见”。它应该像 45 到 75 秒的小动画，而不是规则弹窗。

**分镜**

| 镜头 | 画面 | 字幕/旁白 | 学生理解 |
|---|---|---|---|
| 1. 教室亮灯 | 钢琴教室灯光亮起，老师在谱架旁放下一枚星音徽章 | “每一次认真上课，都会留下回声。” | 课堂表现会被记录 |
| 2. 指尖音符 | 学生按下琴键，音符从谱面飞出，变成蓝金色星光 | “节奏、专注、完成度，会变成伙伴能感受到的力量。” | 练琴不是和游戏分离的 |
| 3. 练琴日记 | 日常练琴记录像日历一样翻页，连续练习让星光更稳定 | “日常练习越稳定，信标越明亮。” | 坚持练习有价值 |
| 4. 老师奖励 | 老师点击奖励面板，能量、金币、补给箱沿光轨进入研究所 | “老师可以把你的表现兑换成能量、金币，甚至意想不到的惊喜。” | 老师奖励和现实表现相关 |
| 5. 研究所响应 | 星光落进研究所核心，五只伙伴的剪影依次亮起 | “现在，轮到你的第一位伙伴回应了。” | 进入伙伴选择 |

**动画语言**

- 音符不是装饰，要有明确路径：`钢琴 → 星光 → 老师奖励光轨 → 研究所信标 → 宝可梦伙伴`。
- 老师奖励出现时用 4 个图标表达：`能量闪电`、`金币`、`补给箱`、`惊喜星标`。
- 惊喜箱不直接展示日之石、王者之证、金属膜，避免当前玩法无用途道具误导。
- 每个镜头 6 到 12 秒，字幕短、画面信息足。
- 首次进入默认播放；复玩或老玩家显示 `跳过动画` 和 `重新观看`。

**可落地奖励说明**

| 动画图标 | 游戏内含义 | 当前可落地范围 |
|---|---|---|
| 能量闪电 | 继续挑战、参与战斗或活动的动力 | 对接现有能量资源 |
| 金币 | 购买精灵球、药剂等补给 | 对接 `playerGold` 和商店 |
| 补给箱 | 老师发放的道具奖励 | 精灵球、药剂、经验药水等现有背包物品 |
| 惊喜星标 | 超出常规的奖励期待 | 稀有补给、隐藏线索、特殊遭遇机会；未来可扩展头像框/称号 |

**关键台词草案**

```text
星音导师：你在课堂上的每一次专注，都会变成信标里的光。
星音导师：每天练琴留下的音符，会为伙伴积蓄力量。
星音导师：当表现足够亮，我可以为你发放能量、金币和特别补给。
星音导师：这些奖励不是凭空出现的，它们来自你真实完成的努力。
星音导师：现在，带着这束光，去选择第一位伙伴吧。
```

### 4.1 第一幕：信标呼唤

**画面**

- 全屏不是传统表单，而是“研究所通讯界面”：中间是星音信标，背后是新手山谷的抽象地图线。
- 顶部只显示 3 个短进度点：`信标`、`伙伴`、`启程`。
- 玩家名显示为档案呼叫对象，不做一整屏“档案卡”。

**文案**

| 元素 | 文案 |
|---|---|
| Kicker | 星音研究所 |
| 标题 | 山谷信标正在呼叫你 |
| 正文 | 你课堂和练琴留下的星光已经抵达研究所。第一段冒险，从一座安静的营地开始。 |
| 按钮 | 回应信标 |

**动画**

- 背景地图线慢慢描边。
- 信标中心 1.8 秒一次轻微发光。
- 进入下一幕时，信标光束向下扫过，过渡到伙伴台。

### 4.2 第二幕：伙伴共鸣

**画面**

- 中央大舞台只展示当前选择的宝可梦。
- 五个初始伙伴在底部或右侧做成短按钮，不占太多文字空间。
- 每只伙伴有一句专属回应，而不是只显示定位说明。

**初始伙伴角色文案**

| 宝可梦 | 角色定位 | 选择回应 | 动画气质 |
|---|---|---|---|
| 小火龙 | 主动进攻 | “它把尾焰举高，像是在说：往前走，我跟得上。” | 火光跳动、落地轻弹 |
| 妙蛙种子 | 稳定成长 | “它安静地靠近你，背上的种子泛起柔和绿光。” | 叶片摆动、呼吸感 |
| 杰尼龟 | 防守可靠 | “它拍了拍龟壳，认真地点了点头。” | 水波扩散、站姿稳 |
| 皮卡丘 | 高速节奏 | “电光一闪，它已经跑到你的脚边。” | 闪电残影、快速眨眼 |
| 伊布 | 长线培养 | “它歪头看着你，像在等待一个共同决定的未来。” | 尾巴摇动、星点闪烁 |

**显示信息**

- 显示属性、定位、三条短能力条：`生存 / 打击 / 速度`。
- 不展示过多数字，避免新手第一分钟进入“算表格”状态。
- 详细属性仍保留在图鉴或队伍页。

**按钮**

- 未选择：`选择伙伴`
- 已选择：`和 {宝可梦名} 共鸣`

### 4.3 第三幕：山谷启程

**画面**

- 左侧或上方是极简路线预览：`营地 → 路牌 → 第一草丛 → 湖边远光`。
- 补给不是四张说明卡，而是 3 个物品图标飞入背包槽：精灵球、伤药、好伤药。
- 能量和金币以“老师奖励通道”形式出现：一条从教室小窗连到背包的小光轨，显示 `课堂表现`、`日常练琴`、`老师奖励` 三个节点。
- 惊喜奖励用一个未打开的星光补给箱表示，只写“老师可能发放更多惊喜”，不展示当前玩法无用途道具。

**文案**

| 元素 | 文案 |
|---|---|
| Kicker | 新手山谷 |
| 标题 | 第一条路已经亮起 |
| 正文 | 带上老师奖励的补给，到营地后先看路牌，再进入草丛。你的伙伴会陪你完成第一次遭遇。 |
| 按钮 | 进入新手山谷 |

**动画**

- 路径从营地点亮到草丛。
- 补给图标依次滑入背包槽，每个间隔 120ms。
- 选中伙伴从舞台轻跳到队伍徽章位置。
- 教室小窗里的钢琴音符再次闪一下，提醒学生“后续奖励来自课堂和练琴表现”。

### 4.4 奖励说明的沉浸式表达

不要把奖励规则放在长篇说明里，而是做成一个“星光流向图”：

```text
课堂表现       日常练琴
  └──── 星光记录 ────┘
          ↓
       星音导师
          ↓
 能量挑战 / 金币 / 补给 / 惊喜
          ↓
 宝可梦冒险、捕捉、培养、挑战
```

在界面中可表现为：

- 左上角一个小小的教室窗口，能看到谱架、琴键和老师徽章。
- 学生练琴音符飞出，沿光轨进入研究所。
- 老师奖励被包装为“星光补给”，从光轨进入背包。
- 背包内每个奖励弹出 1 句解释：
  - 能量：`可以继续挑战，让伙伴保持冒险状态。`
  - 金币：`可以购买精灵球和药剂，准备下一次探索。`
  - 补给：`老师发放的实用道具，会在关键时刻帮上忙。`
  - 惊喜：`表现越稳定，越可能收到特别补给或隐藏线索。`

这部分应在视觉上温暖、鼓励、有仪式感，但不能像“付费抽奖”或“赌博开箱”。惊喜奖励必须表达为老师根据学习表现给予的正向反馈。

## 5. 地图内微剧情任务

任务名：**山谷的第一束回声**

| 步骤 | 触发 | 屏幕反馈 | 目的 |
|---|---|---|---|
| `onboarding_arrive` | `handleStartGame` 进入地图 | 顶部目标条：`查看营地旁的路牌`；伙伴头像短暂弹出 | 给玩家第一目标 |
| `read_camp_sign` | 与 `(8,29)` 路牌互动 | 路牌文本 + 目标更新：`沿土路进入第一片草丛` | 教会互动和草丛规则 |
| `enter_first_grass` | 首次进入安全草丛区域 | 草丛轻晃，触发低压野生遭遇或提高遇敌概率 | 教会遇敌 |
| `first_battle_done` | 第一次战斗结束，无论捕捉、击败、逃跑 | 目标完成弹窗：`你完成了第一次野外练习` | 给闭环反馈 |
| `teacher_reward_hint` | 第一次野外练习完成后 | 星音导师短通讯：`课堂和练琴表现会继续为你点亮奖励` | 再次强化现实学习关联 |
| `first_path_revealed` | 回到地图 | 远处道路/湖边提示短闪，目标改为自由探索 | 引出后续地图 |

### 5.1 任务节奏原则

- 不强迫玩家捕捉成功，因为随机捕捉失败会破坏教学闭环。
- 第一次野生遭遇应低压：敌方等级建议 `Lv.2-Lv.3`，不会秒杀初始伙伴。
- 如果玩家直接绕开草丛，目标条仍显示，但不弹出横幅打断。
- 如果玩家刷新页面，任务状态应从云存档恢复。
- 完成第一次遭遇后不要立刻塞大量奖励，只给一段“老师奖励通道已连接”的剧情提示；真实奖励仍由老师后台发放，避免学生误以为每场战斗都会自动给金币。

### 5.2 地图点位建议

当前出生点：`{ x: 5, y: 30, direction: 'right' }`  
当前教程路牌：`(8,29)`  
当前营地草丛可引导到：`(12,8)` 或 `密林草丛` 入口前的安全草区。

更推荐第一草丛放在营地东北近路，距离控制在 8 到 12 步内：

- 玩家能清楚看到土路连接，不会迷失。
- 路牌和草丛在同一视线逻辑内。
- 草丛附近不要堆太多大树和石头，避免遮挡第一遭遇点。

## 6. 文字播报与节奏

为了避免“战斗或引导过快，文字来不及看”，新手阶段的播报需要单独做节奏控制：

| 场景 | 最短停留 | 可跳过 | 说明 |
|---|---:|---|---|
| 动画序章单镜头 | 3500ms | 是 | 首次播放要像短片，复看可快进 |
| 老师奖励因果说明 | 2200ms | 是 | 必须看懂“练琴表现 → 奖励” |
| 启动页幕间标题 | 450ms | 是 | 快速但能感到转场 |
| 伙伴回应文案 | 900ms | 是 | 切换伙伴时不刷屏，只替换当前文案 |
| 补给入包动画 | 900ms | 是 | 不阻塞太久 |
| 入场第一条日志 | 1200ms | 否 | 第一次进入地图要看清目标 |
| 新手任务目标更新 | 1600ms | 是 | 顶部目标条常驻，不依赖横幅 |
| 第一次遭遇开场 | 1800ms | 否 | 给玩家理解“草丛触发战斗”的时间 |
| 第一次练习完成提示 | 2200ms | 是 | 给学生看到完成闭环 |

实现上建议给新手阶段的日志增加 `priority/onboarding` 标记，而不是全局放慢所有战斗。

## 7. 视觉和动画规格

| 模块 | 动画 | 技术建议 |
|---|---|---|
| 背景 | 地图线缓慢漂移、信标描边 | CSS `transform/opacity`，不使用高成本滤镜 |
| 动画序章 | 教室灯光、琴键音符、练琴日记、老师奖励光轨 | 优先 CSS/SVG 分层动画，必要时用轻量 canvas |
| 奖励因果图 | 课堂表现和日常练琴汇入老师奖励通道 | 图标加短字幕，避免长说明卡 |
| 幕间转场 | 当前幕淡出上移，新幕淡入 | `key={step}` + CSS animation |
| 伙伴舞台 | 呼吸、影子缩放、选中轻跳 | 复用 `MonsterSprite`，外层加 class |
| 初始伙伴按钮 | hover 轻抬、active 描边、图片轻弹 | 移动端只保留 active 弹性反馈 |
| 补给入包 | 图标从左到右进入背包槽 | CSS stagger delay |
| 地图预览 | 路径描边、节点逐个点亮 | SVG 或 CSS path mask |
| 地图内目标条 | 顶部小目标条常驻，完成时变成勾选 | 不再大量弹通知横条 |

移动端要求：

- 单屏尽量不滚动；伙伴选择可横向滚动或 5 格紧凑排列。
- 主按钮固定在底部安全区。
- 标题不超过两行，最长宝可梦名不挤压按钮。
- 不使用大段说明卡，避免手机上像文档。

无障碍要求：

- `prefers-reduced-motion: reduce` 下关闭循环动画和飞入动画，只保留状态切换。
- 启动页区域继续使用 `aria-live="polite"`，但伙伴切换不应连续朗读太多文案。

## 9. 关键边缘情况

| 情况 | 处理 |
|---|---|
| 云存档未加载完成 | 仍先显示 CloudGateScreen，不进入启动页，避免本地假新档覆盖云端 |
| 玩家已有队伍但 `showLaunchScreen=true` | 继续按现有逻辑以 `playerTeam.length` 兜底，不能重新发初始伙伴 |
| 玩家点“回到启动页” | 只能用于无队伍或显式重开；已有队伍不应重复领取补给 |
| 初始伙伴图片加载失败 | 继续使用 `handlePokemonImageError`，启动页不能因为图片失败白屏 |
| 第一次草丛没有遇敌 | 新手任务阶段可临时提高安全草丛遇敌率，完成后恢复 |
| 第一次战斗失败 | 不惩罚，任务提示变为“回营地恢复后再试一次” |
| 玩家逃跑 | 也算完成“第一次遭遇”，但不算捕捉教学完成 |
| 老存档地图版本升级 | 若位置被重置到出生点，不应重新触发新手任务，除非没有 `onboardingQuest.completed` 且队伍只有初始伙伴 |

## 11. 验收标准

新手流程上线后，必须满足：

- 新玩家从进入启动页到进入地图，主流程不超过 3 次主要点击。
- 启动页不再像系统设置页，第一屏即能感到“被召唤进入冒险”，并能看到动画短片式的课堂与练琴因果。
- 学生看完后能明确理解：课堂表现和日常练琴会影响老师可发放的能量、金币、补给和惊喜奖励。
- 每只初始伙伴都有差异化台词、定位和动画气质。
- 地图内第一目标明确，玩家不会进地图后只看到一串日志。
- 第一次草丛、第一次遭遇、第一次战斗结束都有可感知反馈。
- 所有新手信息都能被跳过或自然消失，不打断后续自由探索。
- 老师奖励说明不做成抽奖诱导，不承诺当前系统没有实现的奖励类型。
- 不新增日之石、王者之证、金属膜等当前玩法无用途道具。
- 不影响已有云存档、老师奖励、战斗、捕捉、升级、进化弹窗。

## 12. 推荐执行顺序

1. **先实现阶段 A/A+**：动画序章、启动页三幕重构、老师奖励因果图，这是最直观的体验升级。
2. **再实现阶段 B**：新手任务状态持久化，先修好 `world.flags` 保存链路。
3. **最后实现阶段 C**：地图内微剧情、第一次草丛事件和星音导师完成提示。
4. 每阶段都用浏览器检查桌面和手机视口，防止文字遮挡、按钮拥挤、动画过快。

这套方案的重点不是把规则塞给学生，而是让学生像看动画片一样理解：  
**我认真上课和练琴，老师就能把我的努力变成冒险里的能量、金币、补给和惊喜；我选择伙伴，然后带着真实努力点亮的信标出发。**
