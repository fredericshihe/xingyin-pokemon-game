# 三主力地图难度优化方案与进度记录

## 背景

当前主线地图按「地图探索 -> NPC -> 试炼 -> Boss -> 下一张地图」推进，但在假设玩家从第二张图开始使用 3 只宝可梦作为主力、每张地图拾取宝箱、击败所有 NPC、完成 2 次试炼并额外刷 5 次野怪的路线下，成长仍会在中后期落后 Boss 难度。

这会导致两个体验问题：

- 玩家照着正常探索玩，仍然可能被区域尖峰卡住。
- 如果直接提高全局经验倍率，又会让愿意额外刷怪的玩家快速越级，破坏课堂能量控制。

## 目标路线

本次优化按以下玩家行为作为主线体验目标：

- 从星音草径开始保持 3 只宝可梦主力。
- 每张地图拾取可达宝箱和补给。
- 每张地图击败所有普通 NPC、部下训练师、Boss。
- 每张地图至少完成 2 次区域试炼。
- 每张地图额外击败 5 次野生宝可梦。

## 优化方案

1. 增加「生态调查 0/5」一次性成长奖励。
   - 每张地图首次击败 5 次野生宝可梦时触发。
   - 奖励直接给队伍前 3 只主力分摊经验。
   - 只发一次，记录在 `world.wildDefeatCounts` 和 `world.flags`，避免重复领取。
   - 不提高无限刷怪收益，继续保留能量对游玩时长的控制。
   - 实现时将「出图目标等级」和「生态调查准备目标」拆开：生态调查只把队伍拉到 Boss 前准备区间，后续 NPC、试炼和 Boss 经验自然补齐，避免过度越级。

2. 调整地图补给奖励结构。
   - 中后期宝箱增加经验药水数量，降低「明明探索了但成长不够」的问题。
   - 精灵球和回复药保留，但不再让过多宝箱只给捕捉资源。

3. 调整 Boss 队伍规模节奏。
   - 星音草径、雾湖苇岸：Boss 4 只。
   - 风车农庄、贝壳海岸、月影墓园：Boss 5 只。
   - 六角遗迹、铁木营地、星雾高地：Boss 6 只。
   - 等级不直接大幅降低，优先通过队伍规模和成长供给让难度更像「可准备后通过」。

4. 新增三主力专项审计。
   - 独立于现有 `audit:map-levels`，因为现有脚本主要审计单主力等级上界。
   - 专项脚本会模拟 3 主力、5 次野怪、宝箱、普通 NPC、2 次试炼、Boss。
   - 输出每张地图入口等级、出口等级、Boss 等级差和风险点。

## 风险控制

- 奖励必须在云端快照提交内部计算，避免战斗胜利、刷新、重试时重复发放。
- `wildDefeatCounts` 合并时取最大值，避免本地和云端互相覆盖导致回退。
- 生态调查奖励只看胜利后的野怪计数，不在逃跑、捕捉失败、战败时增长。
- 奖励目标使用队伍前 3 只宝可梦，符合「3 主力」路线，不依赖最后一场野怪是否刚好三只都出战。
- 新审计脚本只读运行时地图配置，不改动实际存档。
