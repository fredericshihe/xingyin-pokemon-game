# 星音界面设计标准 · v1

适用范围：登录注册、教师工作台、学生商店、背包、渔具、鱼商、图鉴、队伍、饲养家、银行，以及共用确认弹窗和操作按钮。地图与战斗的舞台构图继续按各自场景设计；界面控件遵循同一套规范。

## 布局与主次

页面顺序固定为「页面标题 → 当前对象摘要 → 操作分栏 → 内容与操作」。每个表单仅保留一个主按钮，其他动作使用次按钮，危险动作单独置于底部区域。信息只出现一次；效果说明放在物品卡片中，辅助规则在需要时显示。

教师桌面最大宽度 1360px，学生列表宽 300px，主内容占剩余宽度；页面留白 24px，栏间距 24px。1120px 以下列表缩至 272px。760px 以下改为学生列表/详情两页，保留明确返回入口。教师的时长、密码与删除操作只在「账号」分栏展示。

学生功能页留白 20px，手机 12px；卡片网格间距桌面 16px、手机 12px。物品中中文名称为主，英文名称与用途为次，价格与动作固定在下方。

## 字体与尺寸

| 类型 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 24px / 1.4 | 700 | 教师工作台；学生页面 22px |
| 手机页面标题 | 20px / 1.4 | 700 | 窄屏标题 |
| 板块标题 | 18px / 1.5 | 600 | 主要操作分区 |
| 卡片标题 | 14–16px / 1.5 | 600 | 学生、物品与列表主信息 |
| 正文与按钮 | 14px / 1.5–1.7 | 400 / 600 | 表单、操作、说明 |
| 表单标签 | 13px / 1.5 | 600 | 输入字段名称 |
| 英文名、备注、时间 | 12px / 1.6 | 400 | 次要信息 |

不使用 900/950 的超粗字重表达所有信息。字体优先系统中文字体，不增加远程字体加载。

## 控件标准

| 控件 | 高度 | 水平内边距 | 圆角 | 规则 |
| --- | --- | --- | --- | --- |
| 主/次/危险按钮 | 44px | 16px | 10px | 图标与文字相隔 8px |
| 分栏按钮 | 40px | 12px | 8px | 选中为白底与品牌色文字 |
| 桌面紧凑按钮 | 32px | 12px | 8px | 仅快捷预设与筛选 |
| 输入框、选择器 | 44px | 12px | 10px | 单列或双列对齐，边框 1px |
| 登录输入框 | 48px | 12px | 10px | 标准输入文字 16px |
| 图标按钮 | 40px | 居中 | 10px | 必须有可访问名称 |
| 多选框 | 18px | — | — | 与标签同一行 |

触摸设备分栏、快捷预设与筛选至少 44px 高。移动端输入文字 16px，避免浏览器自动放大。原有极紧凑战斗/排序控件可保留显式 32px 尺寸，以适应场景密度。

## 色彩、边界与反馈

页面 `#faf7f0`，卡片 `#ffffff`，文字 `#3f362b`，辅助文字 `#796d5d`，边框 `#e8e0d2`。主按钮恢复原有浅金 `#fde68a` → 琥珀 `#fbbf24` 的轻渐变，文字用深棕 `#5c3b18`；悬停 `#fddd72` → `#f4b518`。品牌文字 `#9a5a16`，选中底色 `#fff5dd`，选中描边 `#e8c88e`，焦点轮廓 `#b77321`。次按钮奶油色 `#fffaf0`，分栏与图片衬底 `#f6f0e5`。危险色 `#b53e4b`，成功 `#237356`，提醒 `#8a641f`。

保留鱼获等级、宝可梦属性等有意义的类别色。全项目共用同一组暖色操作变量；主按钮使用统一轻渐变，次按钮保持浅色，危险按钮保持红色。卡片圆角 16px、弹窗 20px，间距使用 4/8/12/16/20/24/32px，避免厚描边与高强度阴影。

所有动作具备默认、悬停、聚焦、禁用、进行中与错误状态。聚焦使用 3px 可见轮廓。按钮处理中阻止重复提交，错误不清空表单。过渡 140ms，遵从减少动画设置。

## 删除与确认交互

删除入口位于学生「账号」分栏；待审核申请也可删除。弹窗显示昵称、用户名、永久删除影响，默认焦点放在取消按钮；使用浏览器原生 dialog 进行焦点约束和背景隔离。Escape/背景点击可取消，处理中禁止关闭。教师需输入当前密码，由后端再次验证教师角色、审核状态、密码、学生归属与目标用户名。

删除在单一数据库事务内完成，清理账号与关联存档、鱼获、银行、奖励、时长和行为记录。服务器保留私有最小删除收据，用于审计与网络超时重试；不保存密码。已登录学生的云端账号及租约同时失效。测试只使用合成账号，删除真实学生由教师本人发起。

## 实施文件

`src/design/ui-system.css` 是字体、色彩、间距、按钮与认证规范；`src/design/game-ui.css` 规范游戏信息面板；`src/components/Teacher/teacherDashboard.css` 负责教师桌面与手机布局；`src/components/ui/ConfirmDialog.jsx` 提供共用确认交互。开发入口 `/ui-preview` 展示实际教师、登录与注册组件，以及规范参考，不连接测试账号的数据。
