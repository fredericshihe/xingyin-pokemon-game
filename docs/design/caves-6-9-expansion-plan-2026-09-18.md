# 6—9 号地图：特色洞穴、稀有宝可梦与养成扩展规划

日期：2026-09-18。状态：设计方案，尚未实施游戏功能。

本方案基于当前工作区的实际运行时数据，目标为：4 个特色洞穴入口、4 张较小的独立迷宫、每洞 3 只此前没有的新野生稀有宝可梦、终点奖励，以及完整的捕获—升级—进化—招式—特效—图鉴接入。

## 2. 四个洞穴的设计

建议洞穴占原地图面积的约 56%—65%，主路最短约 60—100 步，正常首次探索约 4—7 分钟；时间仅为设计目标，需计入实际遇敌战斗后实测。采用固定布局，刷新和重进不会改变迷宫。

| 宿主地图 | 洞穴 / 建议尺寸 | 入口视觉 | 内部迷宫特色 | 终点 |
| --- | --- | --- | --- | --- |
| 6 月影墓园 | **幽灯墓窟 · 30×24** | 半埋石拱、裂纹墓门、两盏青紫魂灯；靠墓园边缘岩壁，以破损石阶连接支路 | 弯曲墓廊 + 两段环路；壁龛与面具浮雕辨认方向；远处终点有较暖的灯光 | 镇魂石室、封印宝匣 |
| 7 六角遗迹 | **晶核回廊 · 30×26** | 六角石环、铜质纹路、低亮青色晶体；与现有封印密室使用不同入口 | 几何回廊 + 中央环形大厅；三种符号帮助识别分岔；局部晶簇支路 | 晶核大厅、遗迹宝匣 |
| 8 铁木营地 | **铁脉矿洞 · 32×24** | 木梁支撑、矿灯、露出的铁矿石、短段废弃轨道 | 木支架矿道 + 矿车岔道；钢矿仓、掘进面、铁屑岩室三处生态区域 | 深层矿仓、矿工保险箱 |
| 9 星雾高地 | **星陨龙穴 · 32×26** | 陨石裂口、蓝紫晶簇、入口溢出的薄雾 | 岩牙回廊 + 蝙蝠高廊 + 地下古海湖；古海沉积层解释多龙梅西亚的生态来源 | 星落石台、龙纹宝匣 |

每洞包含 1 个入口安全区、3 个有辨识度的生态区、2—3 条短支路、1 个终点奖励区及 1 条通关后开启的返回捷径。主通道约 2 格宽，转角扩大到 3 格；个别短支路可收窄，角色碰撞与视觉通道必须一致。

入口位置在制作灰盒时根据当前地图的道路、NPC、宝箱和模型包围盒选定。当前设计不虚构尚未验证的坐标。入口须能从附近主路看见，通过短支路抵达，并有名称提示及等级提示。

视觉实现采用岩壁模块、入口专属 GLB、晶簇/墓灯/矿灯等主题件。洞顶使用剖开视角，前侧高墙按遮挡规则降低或淡出；不使用完全漆黑的视野制造迷路。四张地图应通过轮廓、布局和地标区分，不能只更换色调。

**每张洞穴恰好增加 3 个新的野生稀有种类，合计 12 个；进化后续增加 11 个形态，总共增加 23 个物种，图鉴从 209 扩展至 232。** 后续形态通过培养获得，首版洞穴遇敌不额外混入这些形态。

## 4. Git 数据来源与生成规则

沿用项目的数据体系：[PokeAPI/pokeapi](https://github.com/PokeAPI/pokeapi) 和 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)。PokeAPI 是整理原作数据的社区项目，并非宝可梦公司发布的官方 Git 仓库。

本次已读取并核对数据仓库提交 **`5c776e225f2150862e021062d7f304c8958368cc`**，13 份 CSV 均通过固定提交 URL 读取并记录 SHA-256。数据证据见同目录 `caves-6-9-data-evidence-2026-09-18.json`。

- 全国编号、简体中文名、普通形态、属性、六项种族值、捕获率、基础经验、成长组分别按对应表生成。
- 新增 23 个物种的升级招式统一选择 **《剑／盾》`sword-shield`（version group 20）**：已核实全部有数据，避免同一家族拼接不同世代学习表。
- 现有生成器默认优先较新版本，因此必须增加按新增物种覆盖的版本配置；未来重生成也要保留这一选择。
- 招式的版本差异要同时核对 `move_changelog`，适用的种族值变更核对 `pokemon_stats_past`；当前证据文件保存的是仓库现值和指定版本学习表，尚未声称完成全部战斗语义核验。
- 原作 level 0 单独保存为“进化时学会”；level 1 用于初始/回忆招式。升级、进化、自动配招和图鉴共用同一份解析结果。
- 原作 PP 作为原始元数据保存；项目使用 MP，MP 消耗继续采用游戏平衡规则，并明确显示。招式合法性不能由 MP 或通用解锁等级倒推。
- `id` 是项目内部编号，`dexNo` 是全国图鉴编号。新增内部编号在实施时从未占用区间分配，现有 209 个 ID 保持稳定。当前可以从 210 开始，但必须在落地前重新检查并行改动。
- 宝可梦立绘及备选精灵资源从 sprites 对应 `dexNo` 获取，先核验再缓存为本地资源；游戏中使用本地路径。

## 5. 遇敌、探索节奏与入口规则

1. 玩家能合法抵达宿主地图，就能探索对应洞穴；采用支线入口，不再收一笔秘境开门费用。首次入口提示说明洞穴普通敌人等级，以及“含较低等级的稀有幼体”。
2. 有效移动进入洞穴可遭遇岩地后进行判定。原地按键、撞墙、打开菜单和暂停均不计步；入口、宝箱、捷径、出口等交互安全格不遇敌。
3. 给遭遇区增加明确的地形/遭遇模式字段，例如 `encounterMode: 'cave'`，由共享规则判断可遭遇地块。使用洞穴专属标记（如 `caveExclusive`），不套用原秘境的“高种族值专属强者”规则。
4. 初始建议：战斗后 **6 个有效岩地步数**不遇敌，之后每步概率 **12%—16%**。平均间隔约 12—14 步；实测以首次通关 4—8 场遭遇为调优目标。
5. 分为前段、中段、深段三套权重，稀有占比建议分别 **10% / 25% / 40%**。它们是“已触发一次遭遇后”的条件概率。各区普通条目之和分别为 90/75/60，三只稀有分别分配为 5/3/2、12/8/5、18/12/10，并按生态调整谁占最高权重。
6. 普通遭遇初稿等级：墓窟 32—38、回廊 38—44、矿洞 44—50、龙穴 55—62。每个普通物种也须与形态等级求交集；不使用整洞等级去再次钳制上表的稀有幼体。
7. 遭遇与捕获沿用野生战斗、精灵球、背包/队伍容量、图鉴登记和体力规则。新的稀有分类不应意外增加 Boss 级捕获惩罚。
8. 捕获、战斗结束、逃跑返回准确触发格；败北遵循现有惩罚并回宿主地图合法恢复点。退出重进恢复位置与遇敌冷却。
9. 全洞可重复探索和捕获；宝箱首次领取后不刷新。首版不追加每日任务或新的计时玩法。

## 6. 招式、升级成长与技能特效

### 6.1 已发现的真实缺口

23 个形态的指定版本升级表去重后有 **141 种招式**：当前项目有 **94 种定义**，另有 **47 种未定义**。有定义只说明可找到配置，仍需检查效果是否完整、学习是否合法、特效是否符合招式语义。

首版建议规则：保存完整原作学习数据，发布一套全部具有真实效果和特效的本版可用招式。下表 10 种是核心新增项；其余 37 种逐项记录暂未开放原因，在图鉴原作资料中标明状态，不进入自动配招或升级选择。这样每条培养线都有可用的招式成长，也能清楚区分“已实现”和“原作存在”。

如后续目标扩展为全部 141 种原作升级招式均可用，则剩余 37 种需要另行完整实现；其中涉及天气、场地钉子、强制换人、特性、PP 操作等当前未完整支持的系统。这部分不能在实施时默默省略，也不能仅给一个通用伤害数值作为完成。

多龙梅西亚原作升级期学招少，应在图鉴明确提示“进化后招式显著丰富”。不能为了填满成长节点加入它原作不会的招式。进化后可回忆新形态已达到等级的招式，并保留玩家选定的合法招式；经验药水连升跨过进化等级时，逐个处理进化与学招事件。

### 6.4 成长与战斗通用要求

- 23 种均接入原作六项种族值、成长组、经验表、基础经验和捕获率；MP 使用现有独立规则。完整核验 Lv.1—100 的经验增长与数值单调性。
- 成长组包括 slow、medium、medium-slow、fast。不得让缺少经验配置的物种无声回退到统一曲线。
- 野生配招、玩家配招、升级学习、进化学习、回忆学习和图鉴引用统一的“物种 + 版本 + 等级 + 本版支持状态”数据。
- 进化时保持实例 ID、个体培养状态及合法配招；HP/MP 按项目现有规则换算。进化和永久图鉴登记在同次可靠存档中完成。
- 每个实际可用招式均要有明确 recipe、材质、运动路径、作用对象、音效及命中时序。复用现有 94 种也须检查完整路径。
- 命中、未命中、免疫、能力提升、状态施加失败、倒下、多段提前击倒和两回合攻击分别播放正确的视觉反馈。
- 当前没有完整特性系统，首版不把恶作剧之心、飘浮、大力士等原作特性写成已生效的战斗优势。

## 7. 终点奖励、返回与存档

以下数值是初始平衡方案，实施时与现有地图经济、药水和商店数据一起复核。

| 洞穴 | 首次抵达终点的宝箱奖励 | 探索记录 |
| --- | --- | --- |
| 幽灯墓窟 | 600 金币 + 超级球×3 + 中经验药水×2 | 幽灯墓窟已探索 |
| 晶核回廊 | 900 金币 + 高级球×2 + 大经验药水×1 | 晶核回廊已探索 |
| 铁脉矿洞 | 1200 金币 + 高级球×3 + 大经验药水×2 | 铁脉矿洞已探索 |
| 星陨龙穴 | 1600 金币 + 高级球×4 + 超级经验药水×1 | 星陨龙穴已探索 |

- 终点格必须有清晰可见的宝箱，到达/交互即可领取，不额外要求击败新 Boss。探索记录是存档标记，首版不增加新货币或背包收藏品。
- 奖励以“洞穴 ID + 宝箱事件 ID”唯一标识。金币、物品、领取状态一并提交；读档、断线重试、跨日及多设备不可重复领取。
- 优先复用现有地图事件去重和原子资源保存。如果现有接口不能确保混合奖励幂等，则加入小范围云端领取 RPC/迁移；客户端隐藏宝箱不能替代服务端去重。
- 领完奖励开启靠近宝箱的返回捷径，传回宿主洞口安全格；正常原路退出一直可用。落点与入口触发格错开，避免连续传送。
- 洞穴按需保存发现状态、当前位置、来源地图/返回落点、已领取事件和捷径状态。规范化、合并、云端保留字段及存档内容版本一并更新。
- 旧存档首次载入时新状态取默认值；保存于洞穴内的存档应能恢复。如果洞穴内容不可用，则安全回宿主洞口。
- 已有永久图鉴和主线奖励不会因总物种数变化而被清空；检查全收集进度和生态调查抽取，避免把未解锁洞穴物种分配给低级玩家。

## 8. 图鉴和玩家界面

新增 23 条目均包括：全国编号、简体中文名、普通形态图片、属性、种族值、成长速度、进化路线、实际可用的升级招式与进化招式。

> 培养提示：幼体升级招式较少；进化时分别学会龙之波动、龙箭。

## 10. 实施顺序与验收
