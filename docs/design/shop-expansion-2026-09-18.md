# 经验药水调整与商店扩充建议

状态：经验药水、极巨糖果和旅行自行车已在本地实现；其余新增道具是设计建议，尚未上架。建议价格需要经过实际游玩调整，不能只凭静态数值保证平衡。

## 经验药水

| 道具 | 当前价格 | 效果 |
| --- | ---: | --- |
| 小经验药水 | 120 | 90 经验 |
| 中经验药水 | 300 | 300 经验 |
| 大经验药水 | 700 | 840 经验 |
| 超级经验药水 | 2000 | 直接升 1 级 |

前三档按用户后续要求从 80／200／480 提高到 120／300／700 金币，每金币经验分别为 0.75、1、1.2，兼顾小额购买和攒钱购买的价值。超级药水价格按用户指定为 2000 金币（2026-09-27 由 1500 上调），适合等级较高、距离下一级较远时使用。它补足当前等级剩余经验，升级后经验归零，最高 100 级；满级、战斗中、库存不足或存档提交失败均不扣药水。正常触发进化选择、技能学习和升级属性刷新。现有超级药水库存及奖励直接沿用新效果。

经济参考：同等级普通野外战斗每击败一只对手，在 Lv.5 / 20 / 50 的金币奖励分别约为 10 / 27 / 55。因此 2000 金币约相当于 200 / 74 / 36 次对应击败奖励；这只是战斗金币参照，不包含课堂、探索和成就奖励。皮卡丘 Lv.50 → 51 需要 7651 经验，Lv.80 → 81 需要 19441 经验，直升药水的价值随等级增加。它比大经验药水划算的分界是剩余经验约 2400，因此早期补经验和后期直接升级各有用途。

## 战术类道具的后续方向

如果之后需要更深的战斗选择，建议先做完整的“携带道具”系统，再上架 2–3 件带明确代价的装备。例如“轻装护符”：速度 +5%，双防 -5%；“稳重护符”：双防 +5%，速度 -5%。两者都应每只只能携带一件、战斗中不能切换、不能叠加，首领与试炼的影响需要另外实测。当前版本不直接加入，以免只增加数值却没有对应取舍和界面。

不建议出售永久属性石、能量恢复、保底稀有遭遇、经验／金币倍增、无条件满血复活或跳过首领的钥匙。这些会绕过现有课堂奖励、挑战与收集节奏。已有免费／低价技能调整也不应重新包装成昂贵的“回忆券”。

## 上架前验收

- 同一笔存档中扣钱、加道具、记持续效果，断网或失败不扣钱；特殊道具允许的使用时机要同时在界面和实际处理函数校验。
- 遭遇香饵用分层抽样：先按原概率抽普通／稀有，再在普通层调整属性权重。固定种子模拟确认稀有概率、金币和经验产出没有提高。
- 喷雾按有效移动而非挂机时间消耗；切地图、重新登录不能续时。相互排斥的道具使用前明确提示，不能静默覆盖已购买效果。
- 道具价格先以 10–20 次完整探索样本验证，观察药水、捕捉球、外观购买占比与玩家是否频繁缺金币，再调整。以上建议价不是已经验证的最终平衡值。
- 外观与相册限制同时加载资源数量；球贴特效优先复用现有粒子系统，低性能设备可以关闭。
