# 100x100 地图宝可梦生态分布规划 V5

> 目标：基于当前 `MONSTERS` 图鉴数据，把已有 144 只宝可梦全部纳入“野生 / 稀有 / 固定隐藏 / 奖励 / 进化专属”的生态账本。  
> 本文只做规划，不修改实际地图和遇敌表。

## 0. 继续可优化点

1. **落地前先修 `wildEncounterRules` 的阶段上限语义**  
   当前 `getSpeciesLevelBounds()` 会把无进化或非等级进化的 `null` 误判成 `0`，导致不少物种出现 `{ max: -1 }`。这些物种如果直接写入野外表会被过滤掉。执行前应把过滤条件改为“仅接受非 null 的整数等级”，无上限物种保持 `max = 100`。

2. **随机野生不要塞满全图鉴**  
   新手山谷虽然扩到 100x100，但仍是一个连贯地图。随机野生应以基础形态、低中阶段和生态合理的独立种为主；最终形态、传说、化石复原、伊布分支、三御家、准神等要作为隐藏/奖励/进化目标，避免破坏成长节奏。

3. **同一生态位只放 5-8 个核心物种**  
   每个区域用“常见 3-4 种 + 少见 2-3 种 + 稀有 1-2 种”。物种太多会让玩家无法形成区域记忆，也会稀释目标捕捉。

4. **最终落地建议拆表，而不是所有区域共用 `route102_grass`**  
   目前地图分区很多，但旧表仍高度复用。100x100 后应新增区域表：`valley_meadow`、`flower_slope`、`mirror_wetland`、`east_shore`、`logging_highland`、`mushroom_wood`、`farm_edge`、`river_delta`、`quarry_scrub`、`metal_yard`、`frost_grotto`。

## 4. 落地权重建议

每张表建议权重总和 100：

- 常见：每只 18-28，总计约 55-70。
- 少见：每只 8-15，总计约 20-35。
- 稀有：每只 2-6，总计约 5-12。
- 极稀有强生态种，例如 #130 幼基拉斯、#131 沙基拉斯、#53 袋兽、#52 吉利蛋，总权重不要超过 3-5。

等级建议：

- 旧图和花丘：Lv.4-12。
- 湿地、东岸、采木高地：Lv.8-24。
- 农田、蘑菇幽林：Lv.12-30。
- 岩场、废弃金属场、岩洞口：Lv.20-42。
- 固定 Boss 或奖励：按任务进度单独给等级，不走随机表。
